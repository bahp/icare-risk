# 🛠️ API Reference

Welcome to the `icare_risk` API documentation. Select a module from the navigation menu to view its functions.

* **[Phenotypes](phenotypes.md)**: The translation layer between raw EHR data and clean, standardized clinical variables (e.g., `has_diabetes`, `derive_age`).
* **[Scores](scores.md)**: Mathematical logic for calculating clinical risk scores (e.g., INCREMENT-ESBL, Charlson).
